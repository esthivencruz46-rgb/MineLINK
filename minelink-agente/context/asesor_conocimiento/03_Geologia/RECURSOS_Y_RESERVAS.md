## Flujo estándar que debe cubrir la base de conocimiento

```
Datos (collar/survey/assay/litho) → QA/QC → compósitos → dominios
→ EDA → variografía → kriging/simulación → modelo de bloques
→ validación (swath, NN, deriva) → clasificación (JORC/CIM)
→ factores modificadores → reservas → reporte técnico (CP/QP)
```
