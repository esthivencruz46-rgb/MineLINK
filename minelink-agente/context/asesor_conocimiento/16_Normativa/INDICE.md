# NORMATIVA — COMPENDIO TRANSVERSAL Y FUENTES DE TEXTO LEGAL

## Dónde obtener SIEMPRE el texto oficial y vigente

| Fuente | Qué es | Enlace |
|---|---|---|
| **SPIJ** — Sistema Peruano de Información Jurídica (MINJUS) | Texto **concordado y actualizado** de toda norma (versión libre disponible) | spij.minjus.gob.pe |
| **El Peruano — Búsqueda de normas legales** | PDF oficial de publicación de cada norma | [V] busquedas.elperuano.pe |
| **gob.pe — Normas y documentos legales** (por institución) | PDFs oficiales MINEM/MINAM/SENACE/OEFA/ANA… | [V] patrón: gob.pe/institucion/<entidad>/normas-legales |
| Compendio **Normativa Sectorial Minería** (Osinergmin en gob.pe) | Colección curada de normas mineras | [V] visto en: https://www.gob.pe/institucion/osinergmin/normas-legales/741887-024-2016-em |
| SINIA (MINAM) | Normas ambientales indexadas | sinia.minam.gob.pe/normas |
| Congreso — archivo digital de leyes | Textos históricos (p. ej. TUO alojado en congreso.gob.pe, verificado en módulo 2) | www2.congreso.gob.pe |

## Mapa normativo mínimo del ciclo minero (checklist del agente)

```
CATEO/PROSPECCIÓN  → libre (con límites: ANP, restos, propiedad)
PETITORIO→CONCESIÓN→ D.S. 020-2020-EM + Ley 26615 (INGEMMET)
EXPLORACIÓN        → D.S. 042-2017-EM (clasif.) + certificación ambiental (DIA/EIA-sd) + CIRA + agua ANA + autorización DGM/GORE
EXPLOTACIÓN        → EIA-sd/EIA-d (D.S. 040-2014-EM) + plan de minado + autorización inicio + terreno superficial + cierre (Ley 28090)
BENEFICIO          → concesión de beneficio + LMP/ECA + vertimientos ANA
PPM/PMA            → Ley 27651 + estratos art. 91 TUO + REINFO/IGAFOM (módulo 1)
TRANSVERSAL        → RSSO (D.S. 024-2016-EM), SST (Ley 29783), consulta previa (Ley 29785) cuando aplique, participación ciudadana (D.S. 028-2008-EM + R.M. 304-2008), cultura (CIRA), SERNANP, SERFOR
CIERRE/POST-CIERRE → Ley 28090 + D.S. 033-2005-EM + garantías; PAM: Ley 28271
```

**Regla del agente:** citar siempre número de norma + artículo + estado de
vigencia con fecha de verificación; ante duda, contrastar en SPIJ.
